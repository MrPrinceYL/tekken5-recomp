# devTextEtc – Texte, alte Fassungen und Bilder aus Devil Within

Erzeugt von `tools/dw_dev_texts.py` aus `extracted/tk5data2` (Spieldaten, nicht in Git).
Einzelheiten: `Tekken5Decomp/DevilWithin.md`, Abschnitt 4.

| Datei | Inhalt |
|---|---|
| `story.txt` | Die Story-Texte der Zwischenspiele (Einleitung, vor Stage 2–5, Ende), Seite für Seite, wie das Spiel sie zeigt (Nachrichten 63–270). Alles davon wird gezeigt; eine frühere Fassung gibt es auf der Disc nicht. |
| `messages_all.txt` | Alle Nachrichten der Datei `cap_teg_msg_font_account` mit Nummer: Zwischenspiel-Zeilen, Hilfetexte der Menüs (271–324), Belohnungen (366–406: Kostümteile der Tekken-5-Figuren, StarBlade). Die Nummern 325–365 fehlen im Index. |
| `menutext.txt` | Die kurzen Menütexte (`cap_teg_msg_font_menutext`). |
| `warp_list_final.txt` | Entwickler-Warpliste `area/mpl.txt` (81 Einträge, inkl. Testkarten). |
| `warp_list_old.txt` | Ältere Warpliste `area/mpl`: Koordinaten statt Wegpunkte, 6 Räume je Gebiet, Ägypten Raum 1/2 vertauscht, ohne die späteren Räume 7–9. |
| `sound_config_final.txt` | Sound-Konfiguration vom 03.02.2005 (u. a. Stimmgruppe „平八の声“ = Heihachi, „2PVoice固定“ = Spieler 2). |
| `sound_config_2005-01-25.txt` | Editor-Sicherung (`.txt~`) vom 25.01.2005: frühere Busse und Lautstärken. |
| `chr_000_final.txt` / `chr_000_old.txt` | Liste des Figuren-Prüfraums und ihre Sicherung (`snd_bg_lab_se` statt `snd_bg_egy_se`). |
| `images/nut_hy_makuma_0.png` | Hintergrund der Zwischenspiele (Mishima-Wappen). |
| `images/nut_hy_instruction_0.png` | Anleitungsbildschirm. |
| `images/nut_menu_font_4_0.png` | Die Schrift, mit der die Texte gezeichnet werden. |
